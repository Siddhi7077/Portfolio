Auditorium / Event Booking System
Overview

A web application built to book and manage auditorium and event spaces, handling scheduling and booking records through a MySQL database.

Technologies
JavaJSPServlets MySQLHTMLCSSJavaScript
Features
  • booking form for users to select events and submit booking details.
  • Auditorium availability checking to view available dates and time slots.
  • Event and booking management for organizing scheduled events and reservations.
What I Learned

Built practical experience in developing a booking-based application, managing event and availability data, designing user-friendly forms, and understanding how different components of an event reservation system work together.
